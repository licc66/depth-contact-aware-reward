运行前先进入项目根目录：

PowerShell:
Set-Location "D:\Users\User\Desktop\双目深度reward"

如果你之后改了文件夹名字，只需要把上面这一行改成新的项目根目录。


1. 验证 WSL2 ManiSkill + mplib + 渲染环境

运行位置：
paper_style_tasks/wsl_verify_maniskill.py

命令：
wsl -d Ubuntu-22.04 -- bash -lc "source paper_style_tasks/wsl_env.sh && python paper_style_tasks/wsl_verify_maniskill.py"

用途：
检查 WSL 虚拟环境、ManiSkill、SAPIEN、mplib、Vulkan CPU 渲染是否都能正常工作。


2. 重新生成 PegInsertionSide 插入任务视频

运行位置：
paper_style_tasks/wsl_run_official_motionplanning.py

命令：
wsl -d Ubuntu-22.04 -- bash -lc "source paper_style_tasks/wsl_env.sh && python paper_style_tasks/wsl_run_official_motionplanning.py --env-id PegInsertionSide-v1 --out-dir paper_style_tasks/outputs/wsl_motionplanning --name peg_insertion_wsl_mplib --seed 0 --num-traj 1 --only-success --max-attempts 10"

输出：
paper_style_tasks/outputs/wsl_motionplanning/PegInsertionSide-v1/motionplanning/peg_insertion_wsl_mplib.mp4

用途：
用 ManiSkill 官方 Panda motion-planning + mplib 重新渲染插入任务。推荐使用这个视频，不推荐继续用旧 guided 插入视频。

5. 如果 WSL 渲染环境坏了，重建本地 Vulkan fallback

运行位置：
paper_style_tasks/wsl_local_vulkan_setup.sh

命令：
wsl -d Ubuntu-22.04 -- bash -lc "bash paper_style_tasks/wsl_local_vulkan_setup.sh"

用途：
不需要 sudo，下载并解压 Mesa/Vulkan 到 /home/jbda/vulkan_local，然后由 wsl_env.sh 自动使用。

9. 运行 GVL-style 本地弱复现 baseline

运行位置：
GVL-style VLM/01_run_gvl_style_local.py

11. 运行 MiMo GVL-style 商用 VLM 小样本 baseline

运行位置：
GVL-style VLM/02_run_mimo_gvl_baseline.py

命令：
wsl -d Ubuntu-22.04 -- bash -lc "source paper_style_tasks/wsl_env.sh && python 'GVL-style VLM/02_run_mimo_gvl_baseline.py' --num-samples 6"

默认模型：
mimo-v2.5

API key 读取顺序：
1. MIMO_API_KEY 环境变量
2. XIAOMI_MIMO_API_KEY 环境变量
3. 项目根目录 mimo apikey.txt

输出：
GVL-style VLM/outputs/three_task_mimo_gvl/mimo_gvl_summary.csv
GVL-style VLM/outputs/three_task_mimo_gvl/mimo_gvl_samples.csv
GVL-style VLM/outputs/three_task_mimo_gvl/mimo_gvl_progress_curves.png
GVL-style VLM/outputs/three_task_mimo_gvl/raw_responses/*.json

用途：
调用 MiMo 对每个任务的采样 RGB 帧进行阶段和 progress 判断。当前为了控制额度，默认每个任务只抽 6 帧。脚本不把 API key 写进代码或输出文件。
