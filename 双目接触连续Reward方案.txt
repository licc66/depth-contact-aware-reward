双目-接触复合 Reward/Progress Model 方案

一、方案定位

在仿真环境中构建一个低开销、可插拔的机器人操作 reward/progress model。该模型不重新训练大型 VLA，也不让 VLM 直接输出动作，而是为现有 RL policy 或 VLA 提供更可靠的任务反馈。

核心思想：用 VLM 提供语义信息，用双目深度提供空间几何判断，用夹爪接触/压力/本体信号提供物理交互确认，三者共同形成复合 reward。


二、输入信息

1. 语义信息
   - RGB 图像和语言指令。
   - 由 VLM、CLIP 或 VLA encoder 提取目标物体、任务意图等语义特征。

2. 双目深度信息
   - 仿真中使用左右目图像、RGB-D 或 ground-truth depth。
   - 提取夹爪-物体距离、深度对齐、物体-目标区域距离等几何信息。

3. 接触/压力/本体信息
   - 使用仿真中的接触力、夹爪开合宽度、夹爪速度、关节状态等。
   - 判断是否有效接触、是否稳定夹持、是否滑移或掉落。


三、复合 reward 组成

整体 reward 不只依赖任务进度，而是由多个物理可验证子项组成：

1. 语义门控
   - 判断当前操作对象是否为语言指令中的目标物体。
   - 如果目标错误，几何接近和接触都不能转化为高 reward。

2. 几何 reward
   - 判断夹爪是否在 3D 空间中接近目标物体。
   - 判断深度方向是否对齐。
   - 判断物体是否靠近目标区域。

3. 接触 reward
   - 判断是否接触目标物体。
   - 判断接触力是否处于合理范围。
   - 惩罚桌面、背景、错误物体等无效接触。

4. 稳定性 reward
   - 判断接触是否持续。
   - 判断物体是否被稳定夹持。
   - 判断是否出现滑移、掉落或夹空。

5. 辅助 progress reward
   - 只作为辅助项，用于表示状态是否整体向任务完成方向推进。
   - 如果 progress 判断与接触、深度等物理信号冲突，以物理信号为准。

6. 失败惩罚
   - 惩罚未接触、错误接触、抓错物体、滑移、掉落、不稳定放置等情况。


四、模型形式

输入：

语义 embedding + 深度/几何特征 + 接触/本体特征 + 最近若干帧历史

模型：

轻量 MLP、GRU、TCN 或小型 Transformer encoder

输出：

1. 语义目标是否正确。
2. 空间几何是否合理。
3. 是否有效接触。
4. 是否稳定夹持。
5. 是否存在失败类型。
6. done probability。
7. 辅助 progress score。

最终由这些输出组合成复合 reward。


五、仿真数据

在仿真环境中采集：

1. 成功轨迹。
2. 普通失败轨迹。
3. near-miss 失败轨迹。

重点构造以下 near-miss：

1. 看起来靠近，但深度未对齐。
2. 看起来抓住，但没有有效接触。
3. 接触了，但接触错误物体。
4. 夹住后发生滑移或掉落。
5. 放到目标附近，但没有稳定放置。

仿真真值用于自动生成训练标签：

1. 目标是否正确。
2. 几何是否对齐。
3. 是否有效接触。
4. 是否稳定夹持。
5. 是否滑移或掉落。
6. 是否成功完成。
7. 失败类型。


六、训练目标

模型不只学习一个 reward 标量，而是学习多个可解释子判断：

1. semantic correctness。
2. geometry alignment。
3. valid contact。
4. contact stability。
5. failure type。
6. done probability。
7. progress score。

同时加入状态排序约束：

稳定夹持 > 接触但滑移
正确目标接触 > 错误目标接触
成功放置 > 目标附近但不稳定
失败前状态 > 失败后状态


七、验证方式

对比以下模型：

1. RGB/VLM-only。
2. depth-only。
3. contact-only。
4. depth + contact。
5. semantic + depth + contact。

主要验证：

1. 是否能更准确判断有效接触。
2. 是否能更准确判断稳定夹持。
3. 是否能识别 near-miss 失败。
4. 是否能减少 RGB/VLM-only 的误判。
5. 是否能更好地给候选轨迹或候选动作排序。


八、预期贡献

提出一个仿真优先验证的空间-接触-语义复合 reward/progress model。

相比纯 RGB/VLM reward，该方案利用双目深度判断空间关系，利用接触/压力判断真实物理交互，从而为机器人操作提供更可靠的任务反馈。
