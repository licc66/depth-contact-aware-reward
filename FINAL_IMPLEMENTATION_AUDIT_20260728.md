## Scientific Boundaries

1. The largest unresolved issue is sensor-domain mismatch. The physical
   checkpoint was trained mainly on simulator-state projections, while the
   online path now supplies noisy SGBM and segmentation-derived geometry.
   The next model should be trained or calibrated on features generated by the
   online adapter itself.
2. PegInsertion depth remains missing because the hole center cannot be
   reliably located from the current whole-box segmentation. No simulator pose
   fallback is used.
3. Renderer segmentation IDs and simulator contact forces are acceptable for
   the current simulation study but are not a real-robot sensor solution.
4. The SAC policy currently observes ManiSkill state. This does not leak into
   the reward model, but a visual-policy/VLA claim requires a separate policy
   observation experiment.
5. The 32-step, one-seed RL run is only integration evidence. A comparison
   requires adequate budgets, multiple seeds, confidence intervals, and all
   three tasks after the sensor-domain gate passes.
6. The success-vs-offset hard-negative accuracy of the current fusion reward
   model is only 0.6667, so precision-sensitive deployment is premature.
